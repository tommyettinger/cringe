Omni-Tiling Noise

A newer feature in Cringe is support for generating tiles of seamless noise that can tile with any other in their set. This library also provides some pre-made noise textures in the folder docs/noiseOmni/. This page shows how they work.

With single-edge, or omni-tiling, noise, the type of edge doesn't matter, and you can select any tiles you want in a grid and have them tile seamlessly. To contrast with Wang tilings, which have two kinds of edges, this shows all edges as pink, to indicate all horizontal seams are compatible and all vertical seams are compatible. The index for a noise texture is written below that texture. All the examples here use Perlue noise, but Perlin and Value noise are also provided.
